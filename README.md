# 설치 방법

## 1. 구글시트
1. 구글 드라이브에 `handmade_data.xlsx`를 업로드합니다.
2. 파일을 열고 **파일 › Google 스프레드시트로 저장**을 누릅니다.
3. 시트 탭 이름(채널 · 제품 · 매장코드 · 재고기록 · 가계부)은 바꾸지 마세요. 앱이 이 이름으로 찾아요.

## 2. Apps Script
1. 새로 만든 구글시트에서 **확장 프로그램 › Apps Script**를 엽니다.
2. `Code.gs` 내용을 전부 붙여넣고 저장합니다.
3. 맨 아래 `setPin()` 안의 `'1234'`를 원하는 PIN으로 바꿉니다.
4. 위쪽 함수 목록에서 `setPin`을 고르고 **실행**합니다. 처음 한 번 권한 허용 창이 떠요.
5. **배포 › 새 배포 › 유형: 웹 앱**을 고릅니다.
   - 실행: 나
   - 액세스 권한: 모든 사용자
6. 배포 후 나오는 **웹 앱 URL**(…/exec)을 복사해 둡니다.

> 나중에 Code.gs를 고치면 **배포 › 배포 관리 › 수정 › 새 버전**으로 다시 배포해야 반영돼요. URL은 그대로예요.

## 3. GitHub Pages
1. GitHub에서 새 저장소를 만듭니다. 비공개(Private) 저장소는 GitHub Pages가 유료 플랜에서만 돼요.
2. `github` 폴더 안의 파일을 저장소 맨 위에 그대로 올립니다: index.html, app.js, style.css, sw.js, manifest.webmanifest, 아이콘들.
3. **Settings › Pages**에서 Branch를 `main` / `/(root)`로 저장합니다.
4. 1~2분 뒤 나오는 주소(https://아이디.github.io/저장소이름/)로 들어갑니다.
5. 첫 화면 숫자 키패드로 PIN을 누르고 **확인**을 누릅니다. (배포 주소는 앱에 들어 있어요)
6. 홈 화면에 추가합니다.
   - 아이폰: Safari 공유 버튼 › 홈 화면에 추가
   - 안드로이드: Chrome 메뉴 › 앱 설치

데이터는 구글시트에만 저장돼요. PIN은 기기마다 한 번 입력하고, 가계부 맨 아래 'PIN 변경'에서 바꿀 수 있어요.

> Apps Script를 **새 배포**로 만들면 주소가 바뀌어요. 그때는 app.js 맨 위쪽 `API_URL`을 새 주소로 바꿔 올리면 돼요. (배포 관리 › 수정 › 새 버전으로 하면 주소 그대로예요)

## 기존 자료 옮긴 내용
- 카테고리 합침
  - 원단 · 키링 → 부자재
  - 배송비 · 택배포장 → 물류비
  - 입점료 → 운영비
  - 수입 etc → 기타 수입
- 개인차입금과 짝지어진 대출 → 투자
  - 개인차입금 수입 + 대출 지출 → 투자금 넣기
  - 대출 수입 + 개인차입금 지출 → 투자금 가져가기
  - 나머지 대출 → 대출 받기 / 갚기
- 예전 대출이자는 카드에서 낸 지출(부가 비용 · 대출이자)로 넣었어요. 앞으로 마통에서 자동으로 빠지는 이자는 정산 › 대출 › 이자 발생으로 기록하면 돼요.
- 정산 입금마다 몇 월분인지 연결했어요.
  - 스마트스토어는 판매일 단위로 연결했어요. 예전 판매일을 몰라 매월 1일로 넣었어요.
  - 아직 안 들어온 정산(비옥 · 메이드바이 · 아이디어스 9월분)은 홈 TO-DO에 떠요.
- 하자 · 마케팅은 예전처럼 합쳐서 관리해요.
- 재고기록 날짜는 예전 자료에 일자가 없어 매월 1일로 넣었어요.
- 수수료는 입금액으로 추정한 값이에요. 채널 설정에서 고칠 수 있어요.
  - 비옥 41% · 메이드바이 38.5% · 온리오니 35% · 굿즈메이트 20% · 아이디어스 15% · 스마트스토어 0%
